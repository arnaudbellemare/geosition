# Hosted Vercel connection (pilot implementation)

This connection saves a Vercel integration token encrypted for a verified website in a GEOSITION workspace. It checks that Vercel reports the website as a verified domain on the selected project. A saved connection does not prove that Vercel still accepts the credential or that ChatGPT can reach the site. This implementation does not automatically retrieve traffic evidence.

Before use, create a Vercel connectable account integration, grant only the project read permission required to look up project domains, set its redirect URL to `https://<public-host>/api/v1/commerce/vercel/callback`, and apply `supabase/migrations/007_vercel_connections.sql`. Configure `GEOSITION_VERCEL_INTEGRATION_SLUG`, `GEOSITION_VERCEL_CLIENT_ID`, `GEOSITION_VERCEL_CLIENT_SECRET`, `GEOSITION_PUBLIC_BASE_URL`, and the existing Fernet `GEOSITION_OAUTH_ENCRYPTION_KEY` in the hosted secret store. Do not commit those values. Verify persistent Supabase storage is configured. Rotating the encryption key without migrating stored credentials requires customers to reconnect.

Vercel integration approval, installation behavior when a customer already has an installation, permission scope, and access to AI traffic metrics need a live pilot before public release. The account owner must authorize the installation and restrict project access in Vercel. Removing a connection in GEOSITION deletes its saved token but does not revoke the Vercel installation; the owner must also remove it in Vercel. Do not interpret a connected project as a signed-request verification.

The guided setup also offers a Vercel dashboard route when the owner supplies a team slug. For a dashboard-originated callback without an OAuth `state`, the initiating workspace and session must still match an unexpired, encrypted start cookie. GEOSITION exchanges the one-time code and checks the verified domain against the selected project, then keeps the encrypted connection pending until the signed-in user explicitly confirms it. Confirmation requires the normal CSRF check and only permits Vercel’s matching installation-completion URL. This route requires a live pilot before it can be described as operational; a saved connection still does not retrieve browser evidence.
