2. Run [your first audit](geo-audit.md).
3. Review the [score rubric](scoring-rubric.md).
4. Copy [Skill Files](skill-files.md) into your AI coding tool.
5. Fix the highest-impact issues.
6. Re-run audits and benchmarks to prove the before/after delta.
