## Principles

1. **Prune first**: redirect or 410 losers with no redeeming intent; update internal links.
2. **Single intent per URL**: split only when search intent truly differs.
3. **GEO / scaled content**: flag risky bulk publishing in `audit-issues.json` (`geo_scaled_content_risk`).
4. **Evidence**: each backlog item should trace to GSC, crawl, or user signal — not “SEO says so.”
